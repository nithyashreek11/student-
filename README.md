# CampusFlow - Student Task Management System

CampusFlow is a responsive web application that helps students
organize tasks, track progress, and manage priorities.

## Features
- Add, search, and filter tasks
- Manage task status and priority
- Track task completion and productivity
- Store tasks using browser local storage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Actions
- GitHub Pages

## DevOps Implementation
- Version control using GitHub
- Automated workflow triggered by pushes to main
- Automated checks for required website files
- Website artifact creation
- Automated deployment using GitHub Pages
- Workflow monitoring through GitHub Actions

## Deployment
The website is hosted using GitHub Pages.
